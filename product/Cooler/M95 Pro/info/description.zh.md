# COOLSERVER M95 Pro

**紧凑型 4U SP3 散热器，6 根热管，128 CFM 高风压风扇，额定 380 W。**

M95 Pro 是该系列最紧凑的型号，高度仅 124.5 mm，但凭借 6 根热管和 5000 RPM、128 CFM 的风扇，依然可压制 380 W。适合前后风道强劲的 4U 机架服务器。

**价格:** 1.040.000 VND
