# JetKVM

**KVM over IP mã nguồn mở siêu nhỏ: 1080p60, độ trễ chỉ 30–60 ms, màn hình cảm ứng.**

JetKVM là KVM over IP nhỏ gọn cỡ bao diêm với phần mềm mã nguồn mở hoàn toàn. Hình ảnh 1080p@60fps truyền qua WebRTC với độ trễ chỉ 30–60 ms nên thao tác từ xa mượt như ngồi trước máy. Màn hình cảm ứng 1,69 inch hiển thị IP và trạng thái, cổng RJ12 cho phép gắn thêm bo ATX, điều khiển nguồn DC hoặc console serial. Truy cập từ xa qua JetKVM Cloud miễn phí (tuỳ chọn) hoặc tự host.

## Điểm nổi bật

- 1080p@60fps, độ trễ 30–60 ms
- Phần mềm mã nguồn mở
- Màn hình cảm ứng 1,69 inch
- Cổng mở rộng RJ12 (ATX, DC, serial)
- JetKVM Cloud miễn phí, tuỳ chọn

## Thông số kỹ thuật

- **Chip xử lý:** Rockchip RV1106 (Arm Cortex-A7)
- **RAM / bộ nhớ:** 256 MB DDR3L / 16 GB eMMC
- **Video:** 1080p @ 60 fps, H.264, độ trễ 30–60 ms
- **Màn hình:** Màn hình cảm ứng IPS 1,69 inch
- **Mạng:** 100 Mbps Ethernet
- **Cổng kết nối:** Mini HDMI vào, USB-C (bàn phím / chuột + nguồn), Ethernet, cổng mở rộng RJ12
- **Bo mở rộng:** Nguồn ATX, điều khiển nguồn DC, console serial (bán riêng)
- **Phần mềm:** Mã nguồn mở (Go + Linux), JetKVM Cloud qua WebRTC (tuỳ chọn)
