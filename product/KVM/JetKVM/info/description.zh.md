# JetKVM

**迷你开源 KVM over IP：1080p60，延迟仅 30–60 ms，带触摸屏。**

JetKVM 是一款火柴盒大小的 KVM over IP，软件完全开源。1080p@60fps 视频通过 WebRTC 传输，延迟仅 30–60 ms，远程操作如同本地。1.69 英寸触摸屏显示 IP 与状态，RJ12 接口可扩展 ATX、DC 电源控制或串口控制台板。可使用免费可选的 JetKVM Cloud 远程访问，也可自行部署。

## 产品亮点

- 1080p@60fps，延迟 30–60 ms
- 开源软件
- 1.69 英寸触摸屏
- RJ12 扩展口（ATX、DC、串口）
- 免费可选 JetKVM Cloud

## 技术规格

- **主控芯片:** Rockchip RV1106 (Arm Cortex-A7)
- **内存 / 存储:** 256 MB DDR3L / 16 GB eMMC
- **视频:** 1080p @ 60 fps，H.264，延迟 30–60 ms
- **屏幕:** 1.69 英寸 IPS 触摸屏
- **网络:** 100 Mbps Ethernet
- **接口:** Mini HDMI 输入、USB-C（键鼠 + 供电）、以太网、RJ12 扩展口
- **扩展:** ATX 电源、DC 电源控制、串口控制台（另购）
- **软件:** 开源（Go + Linux），可选 JetKVM Cloud（WebRTC）
