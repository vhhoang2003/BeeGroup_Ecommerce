# JetKVM

**Tiny open-source KVM over IP: 1080p60, just 30–60 ms latency, touchscreen.**

JetKVM is a matchbox-sized KVM over IP with fully open-source software. 1080p@60fps video streams over WebRTC with only 30–60 ms latency, so remote work feels local. A 1.69-inch touchscreen shows the IP address and status, and the RJ12 port takes add-on ATX, DC power control or serial console boards. Remote access through the free, optional JetKVM Cloud, or self-host it.

## Highlights

- 1080p@60fps, 30–60 ms latency
- Open-source software
- 1.69-inch touchscreen
- RJ12 extension port (ATX, DC, serial)
- Free, optional JetKVM Cloud

## Specifications

- **SoC:** Rockchip RV1106 (Arm Cortex-A7)
- **Memory / storage:** 256 MB DDR3L / 16 GB eMMC
- **Video:** 1080p @ 60 fps, H.264, 30–60 ms latency
- **Display:** 1.69-inch IPS touchscreen
- **Network:** 100 Mbps Ethernet
- **Ports:** Mini HDMI in, USB-C (keyboard / mouse + power), Ethernet, RJ12 extension port
- **Extensions:** ATX power, DC power control, serial console (sold separately)
- **Software:** Open source (Go + Linux), optional JetKVM Cloud over WebRTC
