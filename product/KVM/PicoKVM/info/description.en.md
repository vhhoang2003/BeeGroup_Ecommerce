# Luckfox PicoKVM

**Affordable Luckfox KVM over IP: 1080p60, USB storage emulation for remote OS installs, touchscreen.**

The Luckfox PicoKVM is a compact KVM over IP built on the Rockchip RV1106: it captures HDMI at 1080p@60fps and emulates a keyboard, a mouse and even a USB drive, so you can mount an ISO and install an OS remotely. A 1.54-inch touchscreen shows the IP and status, and it adds Wake-on-LAN, a web terminal, a serial port and GPIO pins to switch the machine on and off. A budget-friendly pick for home labs and development boards.

## Highlights

- 1080p@60fps, H.264 / H.265
- USB drive emulation for remote OS installs
- 1.54-inch touchscreen
- Wake-on-LAN, web terminal, serial
- GPIO power control

## Specifications

- **SoC:** Rockchip RV1106G3, Cortex-A7 @ 1.2 GHz
- **Memory / storage:** 256 MB DDR3 / 8 GB eMMC + microSD slot
- **Video:** HDMI in, 1080p @ 60 fps, H.264 / H.265, 80–200 ms latency
- **USB emulation:** Keyboard, mouse and USB storage
- **Display:** 1.54-inch 240 × 240 touchscreen
- **Network:** 100 Mbps Ethernet
- **Other features:** Audio, UEFI / BIOS access, Wake-on-LAN, web terminal, 1 × serial terminal, custom scripts, GPIO power control
- **Power input:** USB-C
- **Dimensions:** 48.5 × 48.5 × 29 mm
