# Luckfox PicoKVM

**KVM over IP giá tốt của Luckfox: 1080p60, giả lập ổ USB để cài hệ điều hành, màn hình cảm ứng.**

Luckfox PicoKVM là KVM over IP nhỏ gọn dùng chip Rockchip RV1106: thu hình HDMI 1080p@60fps, giả lập bàn phím, chuột và cả ổ lưu trữ USB để gắn file ISO cài hệ điều hành từ xa. Màn hình cảm ứng 1,54 inch hiển thị IP và trạng thái, có Wake-on-LAN, web terminal, cổng serial và chân GPIO để bật/tắt nguồn máy. Lựa chọn tiết kiệm cho home lab và các bo mạch phát triển.

## Điểm nổi bật

- 1080p@60fps, H.264 / H.265
- Giả lập ổ USB – cài OS từ xa
- Màn hình cảm ứng 1,54 inch
- Wake-on-LAN, web terminal, serial
- Điều khiển nguồn qua GPIO

## Thông số kỹ thuật

- **Chip xử lý:** Rockchip RV1106G3, Cortex-A7 @ 1.2 GHz
- **RAM / bộ nhớ:** 256 MB DDR3 / 8 GB eMMC + khe microSD
- **Video:** HDMI vào, 1080p @ 60 fps, H.264 / H.265, độ trễ 80–200 ms
- **Giả lập USB:** Bàn phím, chuột và ổ lưu trữ USB
- **Màn hình:** Màn hình cảm ứng 1,54 inch 240 × 240
- **Mạng:** 100 Mbps Ethernet
- **Tính năng khác:** Âm thanh, truy cập UEFI / BIOS, Wake-on-LAN, web terminal, 1 cổng serial, script tuỳ biến, điều khiển nguồn qua GPIO
- **Nguồn:** USB-C
- **Kích thước:** 48.5 × 48.5 × 29 mm
