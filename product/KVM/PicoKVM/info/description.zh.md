# Luckfox PicoKVM

**高性价比 Luckfox KVM over IP：1080p60，USB 存储模拟远程装系统，带触摸屏。**

Luckfox PicoKVM 是一款基于瑞芯微 RV1106 的小巧 KVM over IP：支持 1080p@60fps HDMI 采集，可模拟键盘、鼠标乃至 U 盘，挂载 ISO 即可远程安装系统。1.54 英寸触摸屏显示 IP 与状态，并支持网络唤醒、Web 终端、串口以及通过 GPIO 控制开关机。是家庭实验室与开发板的高性价比之选。

## 产品亮点

- 1080p@60fps，H.264 / H.265
- U 盘模拟，远程装系统
- 1.54 英寸触摸屏
- 网络唤醒、Web 终端、串口
- GPIO 电源控制

## 技术规格

- **主控芯片:** Rockchip RV1106G3, Cortex-A7 @ 1.2 GHz
- **内存 / 存储:** 256 MB DDR3 / 8 GB eMMC + microSD 卡槽
- **视频:** HDMI 输入，1080p @ 60 fps，H.264 / H.265，延迟 80–200 ms
- **USB 模拟:** 键盘、鼠标与 USB 存储
- **屏幕:** 1.54 英寸 240 × 240 触摸屏
- **网络:** 100 Mbps Ethernet
- **其他功能:** 音频、UEFI / BIOS 访问、网络唤醒、Web 终端、1 路串口、自定义脚本、GPIO 电源控制
- **电源:** USB-C
- **尺寸:** 48.5 × 48.5 × 29 mm
