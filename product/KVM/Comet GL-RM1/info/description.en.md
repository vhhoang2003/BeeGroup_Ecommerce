# GL.iNet Comet (GL-RM1)

**Compact GL.iNet KVM over IP: BIOS-level remote control, 4K video and Gigabit Ethernet.**

The GL.iNet Comet (GL-RM1) turns any PC, server or workstation into a machine you can run from anywhere through a browser or the GL.iNet app: see the screen, type, move the mouse, enter the BIOS and reinstall the OS – even when the system hangs or its own network is down. It captures HDMI up to 4K@30fps, emulates keyboard and mouse over USB-C, transfers files and audio, and has a USB-A port for an ATX board or Fingerbot to switch power remotely.

## Highlights

- BIOS/UEFI-level control
- HDMI video up to 4K@30fps
- Gigabit Ethernet
- File transfer, clipboard, audio
- Power control via ATX board or Fingerbot

## Specifications

- **Model:** GL-RM1 (Comet)
- **CPU:** Quad-core ARM Cortex-A7
- **Memory / storage:** 1 GB DDR3 / 8 GB eMMC
- **Video input:** HDMI, up to 4K @ 30 fps
- **Network:** Gigabit Ethernet (10/100/1000 Mbps)
- **Ports:** HDMI in, USB-C (keyboard / mouse), USB 2.0 Type-A (ATX board / Fingerbot), Ethernet, USB-C power, reset button
- **Power input:** USB-C, 5 V / 2 A (about 3 W)
- **Dimensions / weight:** 80 × 60 × 17.5 mm / 85 g
