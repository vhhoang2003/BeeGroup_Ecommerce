# AMD EPYC 7F52

**16-core / 32-thread Zen 2 server CPU, up to 3.9 GHz, 256 MB L3, socket SP3.**

The AMD EPYC 7F52 is a AMD EPYC 7002 Series (Rome) processor built on the Zen 2 architecture. 16 high-clocked cores with a huge 256 MB L3 (16 MB per core) – one of the fastest per-core EPYC Rome parts. It supports 8-channel DDR4-3200 and 128 PCIe 4.0 lanes, and runs in single- or dual-socket SP3 platforms.

**Price:** 4.420.000 VND

## Highlights

- 16 cores / 32 threads (Zen 2)
- Base 3.5 GHz, boost up to 3.9 GHz
- 256 MB L3 cache
- 8-channel DDR4-3200, 128 PCIe 4.0 lanes
- Socket SP3, 1P/2P
