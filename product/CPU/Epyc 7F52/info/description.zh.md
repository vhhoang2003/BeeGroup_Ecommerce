# AMD EPYC 7F52

**16 核 32 线程 Zen 2 服务器处理器，最高加速 3.9 GHz，256 MB 三级缓存，SP3 插槽。**

AMD EPYC 7F52 属于 AMD EPYC 7002 Series (代号 Rome)，采用 Zen 2 架构。16 颗高频核心搭配 256 MB 超大三级缓存 (每核 16 MB)，是单核性能最强的 EPYC Rome 型号之一。 支持八通道 DDR4-3200 内存和 128 条 PCIe 4.0 通道，可用于单路或双路 SP3 平台。

**价格:** 4.420.000 VND

## 产品亮点

- 16 核心 / 32 线程 (Zen 2)
- 基础频率 3.5 GHz，最高加速 3.9 GHz
- 256 MB 三级缓存
- 八通道 DDR4-3200，128 条 PCIe 4.0
- SP3 插槽，支持单路/双路
