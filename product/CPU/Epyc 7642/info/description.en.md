# AMD EPYC 7642

**48-core / 96-thread Zen 2 server CPU, up to 3.3 GHz, 256 MB L3, socket SP3.**

The AMD EPYC 7642 is a AMD EPYC 7002 Series (Rome) processor built on the Zen 2 architecture. 48 cores, 96 threads and 256 MB L3 – serious multi-threaded power for rendering, compiling and VMs. It supports 8-channel DDR4-3200 and 128 PCIe 4.0 lanes, and runs in single- or dual-socket SP3 platforms.

**Price:** 9.620.000 VND

## Highlights

- 48 cores / 96 threads (Zen 2)
- Base 2.3 GHz, boost up to 3.3 GHz
- 256 MB L3 cache
- 8-channel DDR4-3200, 128 PCIe 4.0 lanes
- Socket SP3, 1P/2P
