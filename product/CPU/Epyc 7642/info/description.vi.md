# AMD EPYC 7642

**CPU máy chủ 48 nhân / 96 luồng, kiến trúc Zen 2, boost tới 3.3 GHz, L3 256 MB, socket SP3.**

AMD EPYC 7642 thuộc dòng AMD EPYC 7002 Series (tên mã Rome), kiến trúc Zen 2. 48 nhân, 96 luồng và 256 MB L3 – sức mạnh đa luồng thực thụ cho render, biên dịch và chạy nhiều máy ảo. Hỗ trợ RAM DDR4-3200 8 kênh và 128 lane PCIe 4.0, chạy được trên mainboard SP3 1 CPU hoặc 2 CPU.

**Giá:** 9.620.000 VND

## Điểm nổi bật

- 48 nhân / 96 luồng (Zen 2)
- Xung cơ bản 2.3 GHz, boost tới 3.3 GHz
- Bộ nhớ đệm L3 256 MB
- RAM DDR4-3200 8 kênh, 128 lane PCIe 4.0
- Socket SP3, chạy 1 hoặc 2 CPU
