# AMD EPYC 7642

**48 核 96 线程 Zen 2 服务器处理器，最高加速 3.3 GHz，256 MB 三级缓存，SP3 插槽。**

AMD EPYC 7642 属于 AMD EPYC 7002 Series (代号 Rome)，采用 Zen 2 架构。48 核 96 线程、256 MB 三级缓存，为渲染、编译和多虚拟机提供强劲多线程性能。 支持八通道 DDR4-3200 内存和 128 条 PCIe 4.0 通道，可用于单路或双路 SP3 平台。

**价格:** 9.620.000 VND

## 产品亮点

- 48 核心 / 96 线程 (Zen 2)
- 基础频率 2.3 GHz，最高加速 3.3 GHz
- 256 MB 三级缓存
- 八通道 DDR4-3200，128 条 PCIe 4.0
- SP3 插槽，支持单路/双路
