# AMD EPYC 7V13

**CPU máy chủ 64 nhân / 128 luồng, kiến trúc Zen 3, boost tới 3.5 GHz, L3 256 MB, socket SP3.**

AMD EPYC 7V13 thuộc dòng AMD EPYC 7003 Series (tên mã Milan), kiến trúc Zen 3. Chip HPC của Azure: 64 nhân Zen 3, xung nền cao 2.45 GHz – hiệu năng sát flagship EPYC 7763. Hỗ trợ RAM DDR4-3200 8 kênh và 128 lane PCIe 4.0, chạy được trên mainboard SP3 1 CPU hoặc 2 CPU.

**Giá:** 19.760.000 VND

## Điểm nổi bật

- 64 nhân / 128 luồng (Zen 3)
- Xung cơ bản 2.45 GHz, boost tới 3.5 GHz
- Bộ nhớ đệm L3 256 MB
- RAM DDR4-3200 8 kênh, 128 lane PCIe 4.0
- Socket SP3, chạy 1 hoặc 2 CPU

## Lưu ý

- Chip OEM/cloud có thể bị khoá nhà cung cấp (AMD Platform Secure Boot). Cần đảm bảo bản bán ra là bản đã mở khoá (unlocked), nếu không CPU chỉ chạy trên mainboard của hãng gốc.
- Zen 3 (EPYC 7003) cần mainboard/BIOS hỗ trợ Milan – ví dụ Huananzhi H12D-8D, hoặc Gigabyte MZ71-CE1 từ rev 3.x trở lên.
