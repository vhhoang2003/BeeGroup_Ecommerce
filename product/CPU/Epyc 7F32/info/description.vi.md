# AMD EPYC 7F32

**CPU máy chủ 8 nhân / 16 luồng, kiến trúc Zen 2, boost tới 3.9 GHz, L3 128 MB, socket SP3.**

AMD EPYC 7F32 thuộc dòng AMD EPYC 7002 Series (tên mã Rome), kiến trúc Zen 2. EPYC 8 nhân xung cao, L3 128 MB – lý tưởng cho phần mềm tính bản quyền theo nhân (database, VMware, Windows Server). Hỗ trợ RAM DDR4-3200 8 kênh và 128 lane PCIe 4.0, chạy được trên mainboard SP3 1 CPU hoặc 2 CPU.

**Giá:** 3.588.000 VND

## Điểm nổi bật

- 8 nhân / 16 luồng (Zen 2)
- Xung cơ bản 3.7 GHz, boost tới 3.9 GHz
- Bộ nhớ đệm L3 128 MB
- RAM DDR4-3200 8 kênh, 128 lane PCIe 4.0
- Socket SP3, chạy 1 hoặc 2 CPU
