# AMD EPYC 7F32

**8-core / 16-thread Zen 2 server CPU, up to 3.9 GHz, 128 MB L3, socket SP3.**

The AMD EPYC 7F32 is a AMD EPYC 7002 Series (Rome) processor built on the Zen 2 architecture. High-frequency 8-core EPYC with 128 MB L3 – ideal for per-core licensed software (databases, VMware, Windows Server). It supports 8-channel DDR4-3200 and 128 PCIe 4.0 lanes, and runs in single- or dual-socket SP3 platforms.

**Price:** 3.588.000 VND

## Highlights

- 8 cores / 16 threads (Zen 2)
- Base 3.7 GHz, boost up to 3.9 GHz
- 128 MB L3 cache
- 8-channel DDR4-3200, 128 PCIe 4.0 lanes
- Socket SP3, 1P/2P
