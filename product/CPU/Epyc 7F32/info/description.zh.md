# AMD EPYC 7F32

**8 核 16 线程 Zen 2 服务器处理器，最高加速 3.9 GHz，128 MB 三级缓存，SP3 插槽。**

AMD EPYC 7F32 属于 AMD EPYC 7002 Series (代号 Rome)，采用 Zen 2 架构。高频 8 核 EPYC，配备 128 MB 三级缓存，适合按核心授权的软件 (数据库、VMware、Windows Server)。 支持八通道 DDR4-3200 内存和 128 条 PCIe 4.0 通道，可用于单路或双路 SP3 平台。

**价格:** 3.588.000 VND

## 产品亮点

- 8 核心 / 16 线程 (Zen 2)
- 基础频率 3.7 GHz，最高加速 3.9 GHz
- 128 MB 三级缓存
- 八通道 DDR4-3200，128 条 PCIe 4.0
- SP3 插槽，支持单路/双路
