# AMD EPYC 7663

**56-core / 112-thread Zen 3 server CPU, up to 3.5 GHz, 256 MB L3, socket SP3.**

The AMD EPYC 7663 is a AMD EPYC 7003 Series (Milan) processor built on the Zen 3 architecture. 56 Zen 3 cores – roughly 19% higher IPC than Zen 2, with boost up to 3.5 GHz. It supports 8-channel DDR4-3200 and 128 PCIe 4.0 lanes, and runs in single- or dual-socket SP3 platforms.

**Price:** 14.300.000 VND

## Highlights

- 56 cores / 112 threads (Zen 3)
- Base 2.0 GHz, boost up to 3.5 GHz
- 256 MB L3 cache
- 8-channel DDR4-3200, 128 PCIe 4.0 lanes
- Socket SP3, 1P/2P
