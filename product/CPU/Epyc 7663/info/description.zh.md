# AMD EPYC 7663

**56 核 112 线程 Zen 3 服务器处理器，最高加速 3.5 GHz，256 MB 三级缓存，SP3 插槽。**

AMD EPYC 7663 属于 AMD EPYC 7003 Series (代号 Milan)，采用 Zen 3 架构。56 颗 Zen 3 核心，IPC 比 Zen 2 提升约 19%，加速频率高达 3.5 GHz。 支持八通道 DDR4-3200 内存和 128 条 PCIe 4.0 通道，可用于单路或双路 SP3 平台。

**价格:** 14.300.000 VND

## 产品亮点

- 56 核心 / 112 线程 (Zen 3)
- 基础频率 2.0 GHz，最高加速 3.5 GHz
- 256 MB 三级缓存
- 八通道 DDR4-3200，128 条 PCIe 4.0
- SP3 插槽，支持单路/双路

## 适用场景

- 3D 渲染 (Blender、V-Ray、Corona)

## 注意事项

- Zen 3 (EPYC 7003) 需要支持 Milan 的主板/BIOS，例如华南金牌 H12D-8D，或技嘉 MZ71-CE1 rev 3.x 及以上版本。
