# AMD EPYC 7663

**CPU máy chủ 56 nhân / 112 luồng, kiến trúc Zen 3, boost tới 3.5 GHz, L3 256 MB, socket SP3.**

AMD EPYC 7663 thuộc dòng AMD EPYC 7003 Series (tên mã Milan), kiến trúc Zen 3. 56 nhân Zen 3 – IPC cao hơn Zen 2 khoảng 19%, boost tới 3.5 GHz. Hỗ trợ RAM DDR4-3200 8 kênh và 128 lane PCIe 4.0, chạy được trên mainboard SP3 1 CPU hoặc 2 CPU.

**Giá:** 14.300.000 VND

## Điểm nổi bật

- 56 nhân / 112 luồng (Zen 3)
- Xung cơ bản 2.0 GHz, boost tới 3.5 GHz
- Bộ nhớ đệm L3 256 MB
- RAM DDR4-3200 8 kênh, 128 lane PCIe 4.0
- Socket SP3, chạy 1 hoặc 2 CPU
