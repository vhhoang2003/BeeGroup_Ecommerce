# AMD EPYC 7532

**CPU máy chủ 32 nhân / 64 luồng, kiến trúc Zen 2, boost tới 3.3 GHz, L3 256 MB, socket SP3.**

AMD EPYC 7532 thuộc dòng AMD EPYC 7002 Series (tên mã Rome), kiến trúc Zen 2. 32 nhân kèm đủ 256 MB L3 – được ưa chuộng cho máy render, ảo hoá và server lập trình. Hỗ trợ RAM DDR4-3200 8 kênh và 128 lane PCIe 4.0, chạy được trên mainboard SP3 1 CPU hoặc 2 CPU.

**Giá:** 8.320.000 VND

## Điểm nổi bật

- 32 nhân / 64 luồng (Zen 2)
- Xung cơ bản 2.4 GHz, boost tới 3.3 GHz
- Bộ nhớ đệm L3 256 MB
- RAM DDR4-3200 8 kênh, 128 lane PCIe 4.0
- Socket SP3, chạy 1 hoặc 2 CPU
