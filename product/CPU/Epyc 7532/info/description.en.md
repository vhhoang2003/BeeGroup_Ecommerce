# AMD EPYC 7532

**32-core / 64-thread Zen 2 server CPU, up to 3.3 GHz, 256 MB L3, socket SP3.**

The AMD EPYC 7532 is a AMD EPYC 7002 Series (Rome) processor built on the Zen 2 architecture. 32 cores with the full 256 MB L3 – a favourite for render nodes, virtualization and dev servers. It supports 8-channel DDR4-3200 and 128 PCIe 4.0 lanes, and runs in single- or dual-socket SP3 platforms.

**Price:** 8.320.000 VND

## Highlights

- 32 cores / 64 threads (Zen 2)
- Base 2.4 GHz, boost up to 3.3 GHz
- 256 MB L3 cache
- 8-channel DDR4-3200, 128 PCIe 4.0 lanes
- Socket SP3, 1P/2P
