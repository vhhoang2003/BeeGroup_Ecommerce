# AMD EPYC 7532

**32 核 64 线程 Zen 2 服务器处理器，最高加速 3.3 GHz，256 MB 三级缓存，SP3 插槽。**

AMD EPYC 7532 属于 AMD EPYC 7002 Series (代号 Rome)，采用 Zen 2 架构。32 核配满 256 MB 三级缓存，渲染节点、虚拟化和开发服务器的热门之选。 支持八通道 DDR4-3200 内存和 128 条 PCIe 4.0 通道，可用于单路或双路 SP3 平台。

**价格:** 8.320.000 VND

## 产品亮点

- 32 核心 / 64 线程 (Zen 2)
- 基础频率 2.4 GHz，最高加速 3.3 GHz
- 256 MB 三级缓存
- 八通道 DDR4-3200，128 条 PCIe 4.0
- SP3 插槽，支持单路/双路
