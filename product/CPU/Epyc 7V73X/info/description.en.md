# AMD EPYC 7V73X

**64-core / 128-thread Zen 3 server CPU, up to 3.5 GHz, 768 MB (3D V-Cache) L3, socket SP3.**

The AMD EPYC 7V73X is a AMD EPYC 7003 Series with 3D V-Cache (Milan-X) processor built on the Zen 3 architecture. Milan-X with 768 MB of stacked 3D V-Cache – 3× the L3 of a normal EPYC, a monster for CFD, simulation and EDA. It supports 8-channel DDR4-3200 and 128 PCIe 4.0 lanes, and runs in single- or dual-socket SP3 platforms.

**Price:** 39.000.000 VND

## Highlights

- 64 cores / 128 threads (Zen 3)
- Base 2.2 GHz, boost up to 3.5 GHz
- 768 MB (3D V-Cache) L3 cache
- 8-channel DDR4-3200, 128 PCIe 4.0 lanes
- Socket SP3, 1P/2P

## Notes

- OEM/cloud chips may be vendor-locked (AMD Platform Secure Boot). Make sure the unit is sold as unlocked, otherwise it only boots on the original vendor's boards.
- Zen 3 (EPYC 7003) requires a board/BIOS with Milan support – e.g. Huananzhi H12D-8D, or Gigabyte MZ71-CE1 rev 3.x and later.
- Milan-X needs a BIOS that explicitly supports EPYC 7003X – check with the board vendor before pairing.
