# AMD EPYC 7V73X

**64 核 128 线程 Zen 3 服务器处理器，最高加速 3.5 GHz，768 MB (3D V-Cache) 三级缓存，SP3 插槽。**

AMD EPYC 7V73X 属于 AMD EPYC 7003 Series with 3D V-Cache (代号 Milan-X)，采用 Zen 3 架构。Milan-X，配备 768 MB 3D V-Cache 堆叠缓存，是普通 EPYC 的 3 倍，CFD、仿真和 EDA 的性能怪兽。 支持八通道 DDR4-3200 内存和 128 条 PCIe 4.0 通道，可用于单路或双路 SP3 平台。

**价格:** 39.000.000 VND

## 产品亮点

- 64 核心 / 128 线程 (Zen 3)
- 基础频率 2.2 GHz，最高加速 3.5 GHz
- 768 MB (3D V-Cache) 三级缓存
- 八通道 DDR4-3200，128 条 PCIe 4.0
- SP3 插槽，支持单路/双路

## 注意事项

- OEM/云端芯片可能存在厂商锁 (AMD Platform Secure Boot)。请确认为无锁版本，否则只能在原厂主板上点亮。
- Zen 3 (EPYC 7003) 需要支持 Milan 的主板/BIOS，例如华南金牌 H12D-8D，或技嘉 MZ71-CE1 rev 3.x 及以上版本。
- Milan-X 需要明确支持 EPYC 7003X 的 BIOS，搭配前请向主板厂商确认。
