# AMD EPYC 7K62

**48-core / 96-thread Zen 2 server CPU, up to 3.3 GHz, 192 MB L3, socket SP3.**

The AMD EPYC 7K62 is a AMD EPYC 7002 Series (Rome) processor built on the Zen 2 architecture. 48 cores at a higher 2.6 GHz base clock than the retail 7642 – lots of threads for the money. It supports 8-channel DDR4-3200 and 128 PCIe 4.0 lanes, and runs in single- or dual-socket SP3 platforms.

**Price:** 9.360.000 VND

## Highlights

- 48 cores / 96 threads (Zen 2)
- Base 2.6 GHz, boost up to 3.3 GHz
- 192 MB L3 cache
- 8-channel DDR4-3200, 128 PCIe 4.0 lanes
- Socket SP3, 1P/2P
