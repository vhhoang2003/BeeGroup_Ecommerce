# AMD EPYC 7B12

**64-core / 128-thread Zen 2 server CPU, up to 3.3 GHz, 256 MB L3, socket SP3.**

The AMD EPYC 7B12 is a AMD EPYC 7002 Series (Rome) processor built on the Zen 2 architecture. Flagship-class 64-core Rome (comparable to the EPYC 7742) at a fraction of the price. It supports 8-channel DDR4-3200 and 128 PCIe 4.0 lanes, and runs in single- or dual-socket SP3 platforms.

**Price:** 15.600.000 VND

## Highlights

- 64 cores / 128 threads (Zen 2)
- Base 2.25 GHz, boost up to 3.3 GHz
- 256 MB L3 cache
- 8-channel DDR4-3200, 128 PCIe 4.0 lanes
- Socket SP3, 1P/2P
