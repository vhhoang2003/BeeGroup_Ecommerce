# AMD EPYC 7B12

**CPU máy chủ 64 nhân / 128 luồng, kiến trúc Zen 2, boost tới 3.3 GHz, L3 256 MB, socket SP3.**

AMD EPYC 7B12 thuộc dòng AMD EPYC 7002 Series (tên mã Rome), kiến trúc Zen 2. Rome 64 nhân đẳng cấp flagship (tương đương EPYC 7742) với giá rẻ hơn nhiều. Hỗ trợ RAM DDR4-3200 8 kênh và 128 lane PCIe 4.0, chạy được trên mainboard SP3 1 CPU hoặc 2 CPU.

**Giá:** 15.600.000 VND

## Điểm nổi bật

- 64 nhân / 128 luồng (Zen 2)
- Xung cơ bản 2.25 GHz, boost tới 3.3 GHz
- Bộ nhớ đệm L3 256 MB
- RAM DDR4-3200 8 kênh, 128 lane PCIe 4.0
- Socket SP3, chạy 1 hoặc 2 CPU

## Lưu ý

- Chip OEM/cloud có thể bị khoá nhà cung cấp (AMD Platform Secure Boot). Cần đảm bảo bản bán ra là bản đã mở khoá (unlocked), nếu không CPU chỉ chạy trên mainboard của hãng gốc.
