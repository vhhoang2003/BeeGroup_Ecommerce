# AMD EPYC 7402

**CPU máy chủ 24 nhân / 48 luồng, kiến trúc Zen 2, boost tới 3.35 GHz, L3 128 MB, socket SP3.**

AMD EPYC 7402 thuộc dòng AMD EPYC 7002 Series (tên mã Rome), kiến trúc Zen 2. EPYC 24 nhân cân bằng – lựa chọn đáng tiền cho home lab, máy chủ ảo hoá/NAS và server doanh nghiệp nhỏ. Hỗ trợ RAM DDR4-3200 8 kênh và 128 lane PCIe 4.0, chạy được trên mainboard SP3 1 CPU hoặc 2 CPU.

**Giá:** 3.380.000 VND

## Điểm nổi bật

- 24 nhân / 48 luồng (Zen 2)
- Xung cơ bản 2.8 GHz, boost tới 3.35 GHz
- Bộ nhớ đệm L3 128 MB
- RAM DDR4-3200 8 kênh, 128 lane PCIe 4.0
- Socket SP3, chạy 1 hoặc 2 CPU
