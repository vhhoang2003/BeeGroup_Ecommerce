# HUANANZHI H12D-8D 1P

**SP3 单路主板，支持 EPYC 7002/7003，4 条 PCIe 4.0 x16、3 个 M.2 NVMe、双 2.5G 网口，标准 ATX 尺寸。**

华南金牌 H12D-8D 让 EPYC 装进普通 ATX 机箱。八通道 DDR4 (最大 2 TB)、4 条全长 PCIe 4.0 x16 插槽可装显卡或 NVMe 扩展卡，3 个 M.2 NVMe 和 3 个 SFF-8643 接口可再扩展 12 块 SATA 硬盘或 U.2 固态，是家庭实验室、渲染主机和 AI 工作站的理想平台。

**价格:** 11.710.400 VND

## 产品亮点

- SP3，支持 EPYC 7002/7003
- 八通道 DDR4，最大 2 TB
- 4 条 PCIe 4.0 x16
- 3 × M.2 NVMe + 3 × SFF-8643
- 双 Intel 2.5G 网口，ATX 板型
