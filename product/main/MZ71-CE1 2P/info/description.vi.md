# GIGABYTE MZ71-CE1 2P

**Mainboard server 2 socket SP3: chạy 2 CPU EPYC, 16 khe RAM, 5 cổng SlimSAS và quản lý từ xa IPMI tích hợp.**

GIGABYTE MZ71-CE1 chạy được 2 CPU AMD EPYC, tối đa 128 nhân trên một bo mạch. 16 khe DDR4 (8 kênh mỗi CPU), tối đa 5 khe PCIe x16, 5 cổng SlimSAS cho ổ SATA hoặc NVMe và chip BMC ASPEED AST2500 với cổng quản lý riêng – nền tảng đã được kiểm chứng cho render farm, cụm ảo hoá và server lưu trữ.

**Giá:** 21.944.000 VND

## Điểm nổi bật

- 2 socket SP3 – tối đa 2 × 64 nhân
- 16 khe DDR4, 8 kênh mỗi CPU
- 5 cổng SlimSAS + 4 SATA + M.2
- BMC ASPEED AST2500 hỗ trợ IPMI
- Nền tảng server chính hãng GIGABYTE

## Lưu ý

- CPU hỗ trợ phụ thuộc revision mainboard: rev 1.x chạy EPYC 7001/7002; EPYC 7003 (Zen 3) cần rev 3.x trở lên. Kiểm tra tem revision trước khi bán kèm CPU Milan.
- Kích thước E-ATX (305 × 330 mm) – cần case hỗ trợ E-ATX / SSI-EEB.
