# GIGABYTE MZ71-CE1 2P

**SP3 双路服务器主板：支持 2 颗 EPYC、16 条内存插槽、5 个 SlimSAS 接口并内置 IPMI 管理。**

技嘉 MZ71-CE1 可同时运行两颗 AMD EPYC 处理器，单板最多 128 核。16 条 DDR4 插槽 (每 CPU 八通道)、最多 5 条 PCIe x16、5 个 SlimSAS 接口可接 SATA 或 NVMe 硬盘，并配备带独立管理网口的 ASPEED AST2500 BMC，是渲染农场、虚拟化集群和存储服务器的可靠平台。

**价格:** 21.944.000 VND

## 产品亮点

- 双路 SP3，最多 2 × 64 核
- 16 条 DDR4，每 CPU 八通道
- 5 × SlimSAS + 4 × SATA + M.2
- ASPEED AST2500 BMC，支持 IPMI
- 技嘉官方服务器平台

## 注意事项

- 支持的 CPU 取决于主板版本：rev 1.x 支持 EPYC 7001/7002；EPYC 7003 (Zen 3) 需要 rev 3.x 或以上。搭配 Milan CPU 销售前请核对版本贴纸。
- E-ATX 板型 (305 × 330 mm)，需要支持 E-ATX / SSI-EEB 的机箱。
